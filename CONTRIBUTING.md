# Contributing to Ludix

Thank you for your interest in contributing to **Ludix**.  
The project is currently in **Phase 0 – Architecture & Documentation**.

Because there is no stable codebase yet, **we are not accepting major code PRs**.  
However, we strongly value:

- Technical discussions  
- Architecture feedback  
- Documentation improvements  
- Translations  
- UX/UI proposals  

When the first working code is published, the following will be added:

- Coding standards  
- Development environment setup  
- Issue labels for “good first issue”  
- A complete contribution workflow  

For now, feel free to open a **Discussion** or **Issue** for ideas, feedback, or questions.
