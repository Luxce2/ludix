# Guía de Contribución a Ludix

Gracias por tu interés en contribuir a **Ludix**.

El proyecto se encuentra actualmente en la **Fase 0 — Arquitectura y Documentación**,  
por lo que **aún no se aceptan Pull Requests grandes de código**.

Sin embargo, tu aporte es bienvenido en:

- Discusión técnica  
- Opiniones sobre arquitectura  
- Revisión de flujos  
- Documentación  
- Traducciones  
- Diseño UX/UI del launcher  
- Branding e identidad visual  

Si quieres aportar ideas o comentarios, abre un **Issue** usando la categoría  
`Discussion` o el tipo de issue que corresponda.

## Cuando exista una base de código estable

Una vez que el proyecto entre en Fase 1:

- Se publicarán issues marcados como **good first issue**.  
- Se describirá el flujo completo de contribución en este archivo.  
- Se definirán estándares de código y estilo.  
- Se documentará el entorno de desarrollo oficial.  
- Se abrirán PRs para módulos específicos del backend, watcher, launcher, etc.

## Gracias

Ludix nace como infraestructura abierta para devolver libertad a los desarrolladores  
y jugadores. Toda contribución —técnica o no técnica— es valiosa.
