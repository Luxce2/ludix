# Código de Conducta de la Comunidad Ludix

Ludix se guía por un principio sencillo:

> **Respeta a los demás.**

Para mantener una comunidad sana, esperamos que todos los participantes:

- Actúen con respeto y buena fe  
- Eviten acoso, discriminación o comportamiento hostil  
- Contribuyan de manera constructiva  
- Mantengan un ambiente colaborativo y amable  

## Comportamientos no aceptados

- Insultos, ataques personales o comentarios despectivos  
- Acoso, amenazas o persecución  
- Contenido discriminatorio (racial, sexual, religioso, etc.)  
- Cualquier intento de sabotear o manipular el proyecto  

## Reportar comportamiento inapropiado

Si encuentras una situación problemática:

1. Evita discutirlo públicamente.  
2. Reporta el incidente mediante un **Issue** privado o  
   directamente al mantenedor del proyecto (correo por definir).  

Este Código de Conducta evolucionará junto a la comunidad.
