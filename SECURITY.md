# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Ludix:

1. **Do not open a public issue.**  
2. Contact the maintainers privately at:  
   **(email to be defined before first release)**

Please include:

- A clear description of the issue  
- Steps to reproduce (if applicable)  
- Possible impact  
- Suggested fixes (optional)

We will review the report and respond as quickly as possible.

Security is a priority for Ludix, especially given the interaction  
with cryptocurrency, payment validation and distribution of executable files.
